## 페르소나 C: 부모 효도형

**프로필**: 
- 성명: 박민준(38) & 이수진(36)
- 직업: 금융사 과장, 대기업 기획팀
- 결혼 예정일: 2026.10.25
- 심리: "부모님께 잘 보여야지", "체계적으로 준비하고 싶다"

**JTBD (When-I Want-So That)**:  
*When* 양가 인사를 다닐 때  
*I Want* 손에 들려 있는 근사한 앨범  
*So That* 부모님께 효도하고 결혼의 현실성을 나눌 수 있다

---

### C-1 (Lv1): 결혼 예정일을 입력하면 체크리스트가 자동 생성되길 원한다

**As a** 부모 효도형 커플  
**I want** 결혼 예정일(10.25) 하나만 입력하면, AI가 D-180부터 D-day까지 준비 일정을 자동으로 제시해주길  
**So that** 무엇을 언제 해야 하는지 구글링하지 않고도 체계적으로 준비할 수 있다

**수용 기준**:
- 체크리스트 15개 항목 이상 자동 생성
- D-180 ~ D+14 범위
- 각 항목에 "언제", "뭘", "왜"가 명확함

---

### C-2 (Lv1): 공유 캘린더에서 부부가 함께 준비 과정을 기록하고 싶다

**As a** 신랑신부 (민준과 수진)  
**I want** 같은 캘린더 페이지에서 우리 둘이 실시간으로 준비 상황을 보고 메모할 수 있길  
**So that** "너는 예물 샀어?", "스드메 언제야?"라는 카톡을 주고받지 않아도 된다

**수용 기준**:
- 월간 캘린더 뷰에서 모든 일정이 보임
- 일정 추가/수정 즉시 반영
- 로그인 없이도 샘플 커플 데이터 조회 가능

---

### C-3 (Lv1): 웨딩촬영을 하면 그 사진을 캘린더 일정에 올려서 한 곳에 모으고 싶다

**As a** 박민준·이수진  
**I want** 웨딩촬영 날짜(8.15) 일정에 스튜디오에서 받은 USB 사진 100장을 드래그 앤 드롭으로 한 번에 업로드할 수 있길  
**So that** "어디에 저장했더라?" 하면서 헤매지 않는다

**수용 기준**:
- 일정별 사진 업로드 가능 (최대 10장)
- 파일 크기 제한 명시 (5MB/장)
- 업로드 후 썸네일로 즉시 표시

---

### C-4 (Lv1): 사진마다 감성 있는 캡션을 AI가 제안해줬으면 좋겠다

**As a** 이수진 (신부)  
**I want** 웨딩촬영 사진을 올린 후 "AI 캡션 추천" 버튼을 누르면, "여름 햇살 아래, 처음으로 웨딩드레스를 입은 날" 같은 감성적인 한 줄이 3개 나오길  
**So that** 앨범에 예쁜 글귀를 어렵지 않게 넣을 수 있다

**수용 기준**:
- 캡션 3개 옵션 제시
- 20~40자 길이
- "우리", "나" 시점의 감성적 표현
- OpenAI API 미사용 시 템플릿으로 폴백

---

### C-5 (Lv1): 준비한 모든 사진을 카테고리별로 정렬해서 "책의 미리보기"처럼 보고 싶다

**As a** 박민준  
**I want** "타임라인" 버튼을 누르면, 웨딩촬영(8장) → 준비의 날들(12장) → 본식(15장) → 신혼여행(10장)처럼 챕터별로 자동 정렬된 미리보기를 볼 수 있길  
**So that** "우리 앨범이 어떻게 될까?"를 미리 확인하고, 마음에 안 드는 사진은 빼기 전에 제거할 수 있다

**수용 기준**:
- 카테고리별 자동 챕터 생성
- 사진 선택/해제 토글 가능
- 각 사진의 캡션 편집 가능
- 챕터 순서 변경 가능 (드래그 또는 버튼)

---

### C-6 (Lv2): 신혼여행 후 "앨범 만들기"를 한 번 클릭해서 주문을 시작하고 싶다

**As a** 이수진 (신부)  
**I want** 타임라인 페이지에서 "이 모습을 앨범으로" 버튼을 누르면, Step 1 (챕터 확인) → Step 2 (판형·표지·수량 선택) → Step 3 (배송지 입력) → Step 4 (주문 완료)를 거쳐 주문이 생성되길  
**So that** 복잡한 절차 없이 5분 안에 주문을 끝낼 수 있다

**수용 기준**:
- 4단계 체크아웃 플로우
- 각 단계마다 "이전"/"다음" 버튼
- 주문 ID 발급 및 표시
- 주문 확인 페이지

---

### C-7 (Lv2): 주문한 앨범의 상태(배송 중, 완료 등)를 언제든 확인하고 싶다

**As a** 박민준  
**I want** "주문 관리" 페이지에서 내가 주문한 앨범(3권)의 상태를 "pending → processing → completed"로 확인할 수 있길  
**So that** "부모님께 언제쯤 드릴 수 있을까?" 하는 기대감을 가질 수 있다

**수용 기준**:
- 주문 목록 조회 (전체, 필터링 가능)
- 주문 상세 (챕터 구성, 사진 수, 배송지, 현재 상태)
- 상태 변경 버튼 (시뮬레이션용)

---

### C-8 (Lv2): 주문할 때 부모님 집에 보낼 수 있도록 수령 정보를 다르게 입력하고 싶다

**As a** 박민준 & 이수진  
**I want** 주문 Step 3에서 "수령인 정보"를 3명(본인, 부모님1, 부모님2) 입력할 수 있길  
**So that** 같은 주문에서 앨범 3권을 세 곳에 각각 배송받을 수 있다

**수용 기준**:
- 수령인 입력 필드: 이름, 연락처, 주소
- 수량과 수령인 개수 일치 검증
- 주문 상세에 각 권의 배송지 표시

---

### C-9 (Lv3): 주문한 앨범의 데이터를 ZIP으로 다운로드해서 언제든 보관하고 싶다

**As a** 이수진  
**I want** 주문 관리 페이지에서 "데이터 다운로드" 버튼을 누르면, order_20261025_001.zip이 다운로드되길  
**So that** 클라우드에 백업하거나 나중에 다시 인쇄할 때 사용할 수 있다

**수용 기준**:
- ZIP 파일 명명: order_YYYYMMDD_XXX.zip
- 내부 구조: order.json + chapters/ + captions.json
- 모든 이미지 파일 포함
- 파일 무결성 검증 (크기, 개수)

---

### C-10 (Lv1): 결혼 예정일로부터 며칠이 남았는지 항상 보고 싶다

**As a** 박민준  
**I want** 홈 페이지 상단에 "성우 ♥ 은비 · D-187" 같이 대형으로 카운트다운을 볼 수 있길  
**So that** 버튼 하나만 봐도 현재 진행 상황이 느껴진다

**수용 기준**:
- 결혼 예정일 기준 자동 계산
- 홈 페이지 상단에 고정 표시
- 폰트 크고 임팩트 있는 디자인

## 페르소나 D: 스몰웨딩/만혼

**프로필**:
- 성명: 한지은(35) & 김태호(37)
- 직업: 프리랜서 디자이너, 스타트업 마케터
- 결혼 예정일: 2026.09.12 (스몰웨딩, 30명 규모)
- 심리: "본식앨범은 너무 비싸다", "우리 느낌을 담고 싶다", "추억만 남으면 된다"

**JTBD (When-I Want-So That)**:  
*When* 본식앨범(100~300만원) 가격에 눈을 떠 있을 때  
*I Want* 저렴하지만 우리만의 스타일을 담은 앨범  
*So That* 예산은 절약하고 추억은 제대로 챙길 수 있다

---

### D-1 (Lv1): 기존 본식앨범의 1/10 가격에 결혼 기록을 남기고 싶다

**As a** 지은 (신부)  
**I want** 본식앨범은 300만원이지만, WeddingLog 앨범은 20만원대에 주문할 수 있길  
**So that** "왜 앨범이 이렇게 비싸?" 하는 질문 없이 부모님께도 선물할 수 있다

**수용 기준**:
- 타겟 가격대: 10~20만원
- "본식앨범 대체재" 포지셔닝
- 자세한 비용 가이드 제시

---

### D-2 (Lv1): 스몰웨딩 준비의 특수성을 고려해달라 (준비 항목이 적으므로)

**As a** 태호 (신랑)  
**I want** 30명 규모의 스몰웨딩이라 예식장·스드메 같은 항목은 스킵하고, 우리 필요한 항목만 체크리스트에 남기고 싶길  
**So that** 불필요한 준비 항목으로 혼란스럽지 않다

**수용 기준**:
- 생성된 체크리스트 삭제/추가 UI 직관적
- 카스터마이징 쉬운 구조

---

### D-3 (Lv1): 준비 과정뿐 아니라 신혼여행의 모든 순간을 앨범에 담고 싶다

**As a** 지은  
**I want** "신혼여행" 카테고리에 태국 여행 사진 20장을 모두 업로드하고, 각각 감성 캡션을 붙여서 마지막 챕터로 만들 수 있길  
**So that** 준비 과정과 신혼여행이 한 권으로 완성되는 추억의 책이 된다

**수용 기준**:
- 일정당 사진 10장 제한이지만, 여러 일정에 걸쳐 가능
- 신혼여행 일정 생성 용이 (날짜 범위 선택)
- 타임라인에서 신혼여행 챕터 하나로 표시

---

### D-4 (Lv1): 사진 없이 메모만으로도 일정을 기록하고 싶다

**As a** 태호  
**I want** 스몰웨딩은 화보 같은 정식 웨딩촬영이 없기 때문에, 사진 없이 메모("10.12 부모님께 폐백 인사 완료")만 남길 수 있길  
**So that** 준비 과정의 모든 이벤트를 기록할 수 있다

**수용 기준**:
- 사진 필수 아님 (선택)
- 메모만으로도 일정 생성 가능
- 타임라인에서 텍스트 일정도 표시

---

### D-5 (Lv1): 직접 찍은 아이폰 사진도 충분히 근사할 수 있다고 믿고 싶다

**As a** 지은  
**I want** "우리는 전문 사진작가 없이 아이폰으로 찍은 사진만 있어도 충분히 이쁜 앨범이 될 수 있다"는 확신을 얻고 싶길  
**So that** 본식앨범을 못해서 느끼는 열등감을 버릴 수 있다

**수용 기준**:
- UX 메시지: "아이폰 스냅 퀄리티로도 충분합니다"
- 더미 데이터에 일반 사진(전문가 미촬영) 포함
- 타임라인의 심플하고 세련된 디자인으로 증명

---

### D-6 (Lv2): 정사각형(21x21cm) 앨범으로 작고 예쁘게 주문하고 싶다

**As a** 지은  
**I want** 주문 Step 2에서 판형을 "정사각형(21x21cm)" 또는 "A4" 중 선택할 수 있길  
**So that** 책장에 예쁘게 꽂을 수 있는 정사각형 사이즈의 책으로 만들 수 있다

**수용 기준**:
- 판형 옵션: SQUARE (21x21cm), A4 (21x29.7cm)
- 각 판형별 가격 표시 (차이 명시)
- 미리보기에서 판형 변경 시 레이아웃 시뮬레이션 (선택)

---

### D-7 (Lv2): 하드커버 선물용이지만 가격은 저렴하게

**As a** 태호  
**I want** 표지를 "하드커버"로 선택하면 좀 더 고급스러워 보이지만, 가격 상승폭은 미미하길  
**So that** "이게 20만원이라고?" 할 정도로 가성비 좋은 선물이 된다

**수용 기준**:
- 표지 옵션: HARD, SOFT
- 하드/소프트 가격 차이 표시
- "선물용"의 이점 강조

---

### D-8 (Lv2): 1권만 자기용으로 주문하고 싶다

**As a** 태호  
**I want** 주문 수량을 "1권"으로 설정할 수 있어서, 자기들만 간직할 수 있길  
**So that** 부모님 보기 민망할 수 있는 신혼여행 사진들도 자유롭게 올릴 수 있다

**수용 기준**:
- 수량 범위: 1~10권
- 수량별 가격 계산 (할인 없음, 단순 곱하기)
- "자기용 1권"도 충분히 의미 있다는 메시지

---

### D-9 (Lv1): 우리가 찍은 사진들이 얼마나 많은지 숫자로 보고 싶다

**As a** 지은  
**I want** 홈 페이지나 타임라인에서 "총 52장의 추억이 저장되었습니다"라는 메시지를 볼 수 있길  
**So that** 기록하는 행동에 대한 뿌듯함과 동기부여를 얻는다

**수용 기준**:
- 총 사진 수 계산 및 표시
- 챕터별 사진 수도 함께 표시
- 매번 로드할 때마다 최신 수치 반영

---

### D-10 (Lv3): 주문 데이터를 다운로드해서 더 예쁜 레이아웃으로 다시 출판하고 싶다

**As a** 지은 (디자이너)  
**I want** 주문한 앨범의 모든 데이터(사진, 캡션, 메타데이터)를 ZIP으로 내려받아서, 자신의 디자인 도구에서 커스텀 레이아웃을 적용해 다른 인쇄사에서 출판할 수 있길  
**So that** 내 디자인 감성을 최대한 반영한 앨범을 만들 수 있다

**수용 기준**:
- ZIP 파일 구조가 명확하고 확장 가능
- order.json에 모든 메타데이터 포함
- 이미지 파일명과 캡션의 매핑이 명확
- 재사용 가능한 형식 (JSON, JPG)

## 페르소나 A, B (2차 타겟, 간략)

### A: 효율 맞벌이 커플
- **특징**: 시간이 없음, 체계적인 가이드 원함
