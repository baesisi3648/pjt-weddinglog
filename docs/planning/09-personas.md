## 페르소나 개요

WeddingLog는 **4개 페르소나**를 식별했습니다.

| 우선순위 | 페르소나 | 특징 | 구매 확률 |
|---------|---------|------|---------|
| **1순위** | **C**: 부모 효도형 | 30대 직장인, 체계적 | 40~50% |
| **1순위** | **D**: 스몰웨딩/만혼 | 만혼, 예산 민감 | 30~40% |
| 2순위 | **A**: 효율 맞벌이 | 시간 부족, 체크리스트 원함 | 20~30% |
| 2순위 | **B**: 감성 기록형 | 추억 중심, SNS 공유 | 25~35% |

**개발 우선순위**: C & D (1순위) → A & B (후속)

| **연소득** | 8,000만원 (개인), 6,000만원 (배우자) |
| **결혼 예정일** | 2026.10.25 |

| **결혼 전경험** | 박민준: 형이 작년 결혼 경험 있음 |

### 심리 프로필

```
"체계적으로 준비하고 싶다"
"부모님께 잘 보여야 한다"
"효도하고 싶다"
"시간이 없어서 좋은 가이드 필요하다"
```

**가치관**:
- 효(孝) 우선: 부모님과의 관계 = 인생의 중요 기둥
- 질서: "계획 없이 하는 일은 없다"
- 신뢰: "믿을 수 있는 정보원을 따른다"

**심리 상태**:
- 설렘: "정말 결혼하는구나"
- 불안: "무엇을 빠뜨렸을까?"
- 부담: "부모님 기대를 충족해야 한다"
- 시간 압박: "회사 일 + 결혼 준비 = 바쁨"

### 일상 시나리오 (하루의 준비)

```
월요일 아침 6시 30분 (회사 출근 전)
  └─ 침대에서 스마트폰으로 "[결혼 준비] D-187" 확인
     "어제 은비가 스드메 미팅 후 사진 올렸네. 저 드레스 좋은데?"

평일 점심시간 12시 30분 (회사 카페)
  └─ "WeddingLog 캘린더" 열기
     "이번 주: 예식장 최종 투어, 스드메 계약 자료 준비, 청첩장 확인"
     "으음, 다음 주 예물 쇼핑도 계획에 넣어야겠다"

저녁 8시 (사무실)
  └─ 은비에게 메시지
     "당신, 오늘 스드메 미팅 사진 좀 봤어? 그 드레스 맞춰서 진행하자"
     "WeddingLog에 올려서 나중에 앨범으로 만들자"

주말 토요일 14시 (예식장 투어)
  └─ 부인 은비와 함께 예식장 3곳 투어
     스마트폰으로 WeddingLog 열기
     "우리 체크리스트에 '예식장 투어' 있네, 오늘 3곳 다 봤으니까 체크!"
     스튜디오에서 제공한 사진 몇 장 업로드
     (아이폰으로 예식장 외관, 홀 사진도 찍기)

일요일 저녁 20시 (집에서)
  └─ 은비와 함께 WeddingLog 타임라인 보기
     "어라, 벌써 우리 준비 과정이 이렇게 많이 쌓였네?"
     "이거 앨범으로 만들면 부모님이 감동하겠는데?"
     "근데 아직 신혼여행까지 남았잖아"
```

### 구매 특성

**구매 패턴**:
- 계획적 구매 (3개월 전부터 알아보기)
- 검색 행동 (블로그 리뷰, 카페 후기)
- 의사결정 느림 (부인, 부모님 의견 조율)
- **수량**: 3~5권 (본인, 양가 부모님 각 1권)

**가격 민감도**:
- 낮음 (연소득 1.4억 = 월 1천 2백만)
- "품질이면 가격은 상관없다" (심사자가 평가)
- 부모님 선물용이므로 "저렴하면 오히려 불안"

**시간 민감도**:
- 극상 (양가 인사 타이밍 = 결혼식+1~2주)
- "앨범 없으면 어색하다" (실제 경험담)

**구매 결정 요인** (중요도순):
1. **타이밍**: 결혼식+2주 내 수령 가능한가?
2. **품질**: 부모님께 줄 만한 앨범인가?
3. **완성도**: 우리 준비 과정이 충분히 담겨 있는가?
4. **가격**: 20만원 내외는 괜찮은가?

### 사용 시나리오 (WeddingLog 도입 후)

```
목표: "준비 과정 기록" + "부모님 선물 앨범"

Flow:
1. 6개월 전: WeddingLog 설치, 결혼 예정일 입력
   → AI 체크리스트 자동 생성
   → "어? 이렇게 많이 할 일이 있어?" (놀람)

2. 4개월 전: 준비 과정 기록
   → 매주 일정 추가 (예식장 투어, 스드메 미팅)
   → 사진 업로드 (스튜디오, 아이폰)
   → AI 캡션 제안받기 ("여름 햇살 아래, 처음으로...")

3. 2개월 전: 타임라인 확인
   → "어라, 벌써 우리 앨범 모양이 보여?" (감동)
   → "총 50장이 쌓였네"
   → 부모님께 미리 타임라인 사진 공유

4. 결혼식 D+3 (신혼여행 출발 직전):
   → 신혼여행 사진 업로드
   → "앨범 주문하기" 클릭
   → 4단계: 정사각형 하드커버 3권 선택
   → 수령인: 본인, 아버지, 어머니 (각각 주소)

5. 결혼식 D+14 (부모님 방문):
   → 양가 부모님께 앨범 전달
   → "우리 결혼 준비 과정을 책으로 만들었어요"
   → 부모님: "아이고, 고마워. 너희 과정이 다 담겨있네" (감동)

결과: 효도 ✓ / 타이밍 ✓ / 품질 ✓ / 의미 ✓
```

## 사용자 여정 맵 (Customer Journey Map)

```
Stage 1: 인식 (Awareness)

  ─────────────────────────────────
```
