# 07 — Business Model

> 수익 구조, 가격 전략, GTM, 단위경제학

---

## 개요

WeddingLog는 **결혼 준비 기록 서비스**를 본체로, **앨범 주문**을 수익화의 부가 기능으로 설계했습니다.

**핵심 가정**: 스위트북(Sweetbook)은 포토북 인쇄 인프라를 가진 파트너사이며, WeddingLog는 스위트북의 "수요 매칭 미들웨어" 역할

---

## 수익 구조 (Hybrid Model)

### 1차 수익: 앨범 주문 수수료

**모델**: B2B2C (Business-to-Business-to-Consumer)

```
WeddingLog ←→ 스위트북 ←→ 최종 소비자 (커플)

흐름:
1. 커플이 WeddingLog에서 앨범 주문
2. WeddingLog가 주문 데이터를 스위트북에 전달
3. 스위트북이 인쇄 후 배송
4. WeddingLog는 주문액의 10~20% 수수료 획득
```

**예시 계산**:
- 주문 가격: 170,000원 (정사각형 하드커버 1권 = 150,000 + 20,000)
- 스위트북 인쇄 원가: 80,000원 (추정)
- WeddingLog 수수료: 17,000원 (10% 수익률)
- 스위트북 순이익: 73,000원 (43% 수익률)

**수수료율 가정**: 10~20% (스위트북과의 파트너십 협상 예정)

### 2차 수익: AI 기능 프리미엄 (향후)

**모델**: SaaS (Software-as-a-Service) 구독

```
Lv1: 기본 체크리스트 + 캡션 일부 무료
Lv2: 무제한 AI 캡션 + 앨범 구성 추천 (월 3,000원)
Lv3: 고급 AI 기능 + 우선 배송 (월 9,900원)
```

**예상 전환율**: 주문 고객의 10~20%가 구독 (현재는 미구현)

### 3차 수익: 포토카드 & 액자 (향후)

**모델**: 추가 상품 판매

```
- 베스트 사진 낱장 포토카드 (10장 세트 9,900원)
- 액자 인화 (A4 사이즈 29,900원)
```

**판매 빈도**: 주문 고객의 30~40% (추가 주문)

## 가격 전략 (Pricing)

### 타겟 가격대

**목표**: 10~20만원 (본식앨범 100~300만원의 1/10~1/5)

### 가격 구조

| 항목 | 정사각형 (1:1) | 가로 양장본 (3:2) |
|------|---------------|------------------|
| 기본가 (소프트커버) | 150,000원 | 180,000원 |
| 하드커버 추가 | +20,000원 | +20,000원 |

**판형 선택 시 추가 비용 (정사각형 → 가로 양장본)**: +30,000원 (기본가 차이로 자연 반영)

**판단 근거 — 하드커버 가격 균일화 (+20,000원)**:
- MVP 단순성: 4 가지 조합(SQ-SOFT / SQ-HARD / A4-SOFT / A4-HARD) 가격 매트릭스를 *기본가 차등 + 커버 균일* 으로 단순화 → 사용자가 옵션 선택 시 *판형 차이만 가격에 반영* 되어 의사결정 부담 감소.
- 인쇄 단가 정합: 하드커버 가공비는 판형과 무관하게 *제본 공정* 에서 발생하므로 판형별 차등을 두는 것이 오히려 비합리적이라 판단.

**수량 할인** (미구현, 선택):
- 1~2권: 정가
- 3~5권: 5% 할인
- 6~10권: 10% 할인

### 가격 근거

**1. 경쟁 분석**:
- 스냅스 포토북: 3~7만원 (작은 사이즈)
- 본식앨범: 100~300만원 (고가)
- WeddingLog: 10~20만원 (중간값, 품질 차별화)

**2. 원가 추정** (스위트북 기준):
- 인쇄비: 80,000원/권 (페이지 수에 따라)
- 유통비: 5,000원/권
- 마진율: 40~50% (스위트북 기대)

**3. 포지셔닝**:
- "본식앨범 대체재" (부모님 선물용, 고급스러움)
- "결혼 준비 과정의 온전한 기록" (스냅스는 사진만)

## Go-to-Market (GTM) 전략

### 타겟 세그먼트

| 세그먼트 | 특징 | 초기 타겟 규모 |
|---------|------|-----------|
| **페르소나 C**: 부모 효도형 | 30대 직장인, 체계적 준비 | 2,000명/년 |
| **페르소나 D**: 스몰웨딩 | 만혼, 예산 민감 | 1,000명/년 |
| **페르소나 A/B**: 2차 | 효율/감성 중시 | 500명/년 |

**연간 타겟**: 3,500명 (한국 결혼 커플 20만 쌍의 1.75%)

### 시드링 채널 (초기 100명 확보)

#### 1. 예비신부 커뮤니티 (온라인)

**플랫폼**:
- 예맘보 (예비맘 카페)
- 다이젝트 (결혼 준비 커뮤니티)
- 웨딩 노하우 블로그

**전략**:
- 공동 창립자/초기 사용자 30명 모집
- "결혼 준비 과정을 기록하고 앨범으로" 주제의 포스팅
- 사용 후 리뷰 작성 유도 (인센티브: 할인 쿠폰)

**예상 전환율**: 포스팅 조회 100명 → 10명 회원 가입 → 2명 주문

#### 2. 웨딩 박람회 & 웨딩페어

**전략**:
- 웨딩페어 부스 운영 (iPad에서 프로토타입 시연)
- QR 코드로 베타 회원 등록
- 현장 가입자 50% 할인 쿠폰

#### 3. 인플루언서 & 웨딩 블로거

**전략**:
- 결혼 준비 블로거 5~10명과 협력
- 서비스 무료 체험 후 리뷰 게시
- 블로그 링크 → WeddingLog 유입

### 초기 성장 (100명 → 500명)

**페르소나 D의 SNS 입소문 유도**:

```
WeddingLog 사용자 D (디자이너)
  → 감성적인 타임라인 스크린샷을 인스타그램에 공유
  → "우리 준비 과정이 한 권의 책이 되었어요" 캡션
  → 팔로워들이 "어디서 만드나요?" 댓글
  → WeddingLog 링크 프로필에 붙여넣기
  → 유기적 입소문 성장
```

**바이럴 가능성**:
- 타임라인의 아름다운 비주얼 (파스텔 컬러, Fraunces 폰트)
- "준비 과정 + 결과물(앨범)" 스토리의 감성성
- 인스타그램 Reel / TikTok 활용 (30초 이내 "변신" 영상)

### 지속 성장 (500명 → 3,500명/년)

**전략**:
1. 콘텐츠 마케팅 (블로그, SEO)
2. 제휴 (웨딩 업체, 청첩장 서비스와의 크로스링크)
3. 입소문 (Net Promoter Score 70+ 유지)

## 스위트북 파트너십 가치 제안

### WeddingLog의 관점

**Why 스위트북인가?**
- 포토북 인쇄 인프라 보유 (자체 구축 불가)
- 빠른 배송 (1~2주 내) + 고품질 인쇄
- 비용 효율성

### 스위트북의 관점

**Why WeddingLog인가?**

**1. 새로운 수요 창출**
```
기존: 스냅스, 셀카 등 "후작용 포토북" 시장만 존재
신규: WeddingLog가 "결혼 준비 기록" 신규 시장 개척

→ 스위트북 입장: 경쟁이 적은 시장 선점
```

**2. 데이터 매칭 기능**
```
스위트북이 직접 제공하려면:
- 앱 개발 비용: 수억 원
- 운영 비용: 월 수천만 원
- 개발 인력: 엔지니어 3~5명

WeddingLog가 제공:
- 데이터 구조화 (order.json + chapters + captions)
- 사용자 인터페이스 (캘린더, 타임라인)
- 고객 관계 (피드백, 개선)

스위트북 입장: "외부 파트너가 시장 개척, 우린 인쇄만" → 수익률 높음
```

**3. 우량 고객 확보**
```
WeddingLog 사용자의 특징:
- 의도적 행동 (능동적으로 기록)
- 높은 구매력 (부모님 선물)
- 재구매 가능성 (3~10권 주문)

스냅스 같은 기존 경쟁사:
- 반사적 행동 (자동 저장)
- 가격 민감 (3~7만원)
- 단회 구매

→ WeddingLog 고객이 수익성 2~3배 높음
```

## 단위경제학 (Unit Economics)

### 고객 수명 가치 (LTV: Lifetime Value)

```
시나리오: 30대 커플의 LTV

1차 주문 (본편 앨범)
  - 주문: 정사각형 하드커버 3권
  - 가격: 630,000원
  - WeddingLog 수수료 (15%): 94,500원

2차 주문 (선택) - 확률 30%
  - 포토카드 세트 + 액자 (평균)
  - 가격: 59,000원
  - 수수료 (20%): 11,800원

3차 주문 (선택) - 확률 10%
  - 추가 앨범 (조카, 친구용)
  - 가격: 180,000원
  - 수수료: 27,000원

AI 구독 (선택) - 확률 15%, 평균 3개월
  - 월 3,000원 × 3 = 9,000원
  - 마진률 80% = 7,200원 순이익

═══════════════════════════════════════
LTV = 94,500 + 11,800×0.3 + 27,000×0.1 + 7,200×0.15
    = 94,500 + 3,540 + 2,700 + 1,080
    = 101,820원
```

### 고객 확보 비용 (CAC: Customer Acquisition Cost)

```
초기 시드링 (100명 확보)
  - 커뮤니티 마케팅: 100만원 (시간)
  - 웨딩페어 부스: 200만원 (부스료 + 인력)
  - 인플루언서 협력: 300만원 (무료 쿠폰)
  - 총: 600만원

CAC = 600만원 / 100명 = 60,000원/명

성장기 (500명 추가)
  - 입소문 (SNS 바이럴)
  - 블로그 SEO
  - 제휴

CAC = 500만원 / 500명 = 10,000원/명 (약 83% 감소)

안정기 평균 CAC: 20,000원/명
```

### 손익분기점 (Payback Period)

```
LTV: 101,820원
CAC: 20,000원
LTV/CAC = 5.09 (이상적: 3~5배)

Payback Period:
  첫 주문 시 수수료: 94,500원
  투자 회수: 20,000원 / 94,500원 = 5.3개월

→ 5개월 내 고객 확보 비용 회수, 이후 순이익
```

### 5년 사업 모델 추정

```
Year 1 (초기 시드링):
  - 신규 고객: 100명
  - ARPU (Average Revenue Per User): 101,820원
  - 총 수익: 1,018만원
  - 마케팅 비용: 600만원
  - 개발/운영 인력: 500만원
  - 순손실: 81만원 (투자 회수 단계)

Year 2 (성장기):
  - 신규 고객: 500명 (이전 100명 포함 총 600명)
  - 기존 고객 재구매율 20%
  - 총 수익: 6,109만원
  - 마케팅 비용: 2,000만원
  - 개발/운영 인력: 1,500만원
  - 순이익: 1,609만원

Year 3 (가속 성장):
  - 신규 고객: 1,500명 (누적 2,100명)
  - 총 수익: 1.89억원
  - 마케팅 비용: 3,000만원
  - 인력: 2,000만원 (팀 확대)
  - 순이익: 7,900만원

Year 4-5: 연 30~40% 성장, 순이익 2억원 규모
```

### 주의사항

```
위 추정은 "낙관적 시나리오"에 기반:
- 실제 전환율은 30~50% 낮을 수 있음
- 스위트북 수수료율 협상에 따라 좌우
- 경쟁사 진입 (기존 포토북 업체의 웨딩 서비스 추가)

리스크 완화:
- 초기 100명의 실제 데이터로 가설 검증
- 분기별 코호트 분석 (재구매율, LTV 추적)
- 스위트북 외 다른 인쇄사와의 협력 검토
```

## 스위트북 외 수익 다각화 (향후)

### 1. 직접 인쇄 (in-house)

```
장점:
- 수수료 100% 확보 (현재 15%)
- 가격 경쟁력 (원가 절감 20%)

단점:
- 초기 투자: 5억원+ (인쇄기, 창고)
- 운영 복잡도 ↑ (품질관리, 배송)
- Year 3 이후 고려

타이밍: Series A 펀딩 후 (순이익 9천만원 달성 후)
```

### 2. 예식장 연동 (Venue Integration)

```
현재: WeddingLog는 독립적 기록 앱

향후: 예식장 공식 매뉴얼로 등록
  → 예식장이 신혼부부에게 WeddingLog 추천
  → CPA 30% 감소 (추천 채널의 신뢰도)
  → 수수료 수익 10배 증가 가능

예시 제휴처:
- 예식당 (예식장 검색, 예약)
- 스튜디오 (웨딩촬영업체)
- 청첩장 (모바일 청첩장)
```

### 3. 스폰서십 & 광고 (선택적)

```
조심스러운 영역 (감성 훼손 위험):
- 화장품, 링 광고는 가능
- 다른 웨딩 서비스 광고는 경쟁 충돌

비침습적 형태:
- 예식장, 스드메 업체 "추천 파트너" 배지
- 요금 없이 노출만 제공
- 우량 고객 접근성으로 파트너사 가치 제공
```

## 경제적 지속가능성 평가

### 강점
- ✅ 높은 LTV/CAC 비율 (5배 이상)
- ✅ 기존 앨범 시장의 공백 (3~20만원대)
- ✅ 바이럴 가능성 높음 (SNS 시각적 콘텐츠)
- ✅ 반복 구매 가능 (3~10권 주문)

### 약점
- ❌ 수익 의존도 (스위트북 15% 수수료)
- ❌ 계절성 (결혼 준비는 3~9월 집중)
- ❌ 경쟁 진입 장벽 낮음 (기술적으로는 복제 용이)

### 기회

## 결론

WeddingLog의 비즈니스 모델은 **"수요 창출"** 기반입니다.

기존 포토북 시장은 "이미 찍은 사진을 책으로"였다면, WeddingLog는 **"준비 과정 자체를 기록하도록 유도"**해서 새로운 수요를 만들어냅니다.

이로 인해:
- 스위트북은 새로운 시장 획득
- 커플은 저렴하고 빠른 앨범 확보
- WeddingLog는 지속 가능한 수익 창출

**성공의 핵심**: 초기 100명의 높은 만족도와 입소문 → 연쇄 성장
